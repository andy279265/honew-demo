# HONEW STUDIO | 候鳥影像工作室

候鳥影像 (Honew Studio) 專注於空間攝影與品牌影像呈現，我們透過精準的光影捕捉，將建築語彙轉化為沈靜的敘事，為每一場域記錄下最真實的靈魂。

## 品牌理念

我們如同候鳥，追求光影遷徙的極致時刻。在建築空間的剛性與影像藝術的柔性之間，我們尋求平衡，致力於將空間設計師的思考，透過鏡頭精準對焦並傳遞予觀眾。

## 技術與架構

本網站為響應式形象官網，採用輕量化架構設計，確保極致的載入效能：

* **核心開發**：HTML5, Tailwind CSS
* **互動動效**：GSAP (GreenSock Animation Platform) - 用於平滑滾動視差與元件漸顯動畫
* **作品呈現**：自適應燈箱 (Lightbox) 系統，內建作品參數動態顯示
* **效能優化**： Intersection Observer API 實現圖片懶載入 (Lazy Loading)
