HONEW / SOUND ARCHIVEPLATE 06 — METHODOLOGY
DATA BEFORE STORY

研究，先有依據。

一份好的音樂回顧，應該能分清楚數據、解讀與想像。

01

從完整播放紀錄出發

接受 Spotify 官方匯出的 Extended Streaming History ZIP／JSON；按台灣時間統計，排除無歌曲資訊的項目。

02

數據和推論分開

播放時長、年度排名與時段分布可以驗證；音樂人格、情緒與曲風仍需其他可靠資料，不憑空斷言。

03

紀錄只留在你的裝置

匯入檔案在本機解析，不存到候鳥伺服器。匯出的圖片由瀏覽器產生；清除或重整網頁即可清掉此次分析。

好的回顧不是替你定義自己，
而是替你保留看見自己的線索。

IMPORT / HOW IT WORKS

讓播放紀錄
長成一份研究。

Spotify 資料申請完成後，將 ZIP 或多個 JSON 檔匯入這個網站，六張圖卡會直接以真實資料更新。帳戶與 ChatGPT 已連接並不代表網站能取得授權；本版本採用本機檔案匯入，不需要輸入 Spotify 密碼。

可匯入官方長期播放紀錄與常見的歷史 JSON 格式。原始播放資料不會上傳、分享或保存於網站。曲風、情緒與藝術家音樂背景的深入研究，將在獲得可靠補充來源後製作。
